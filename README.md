Проект: Построение сборочного конвейера

Необходимо построить конвейер сборки из следующих шагов:

- Получение исходного кода из вашего проекта Задание 4 (git)
- Компиляция кода программы и тестов (mvn)
- Запуск тестов (только для веток feature/XXX) (mvn)
- Запуск статического анализатора (любой из checkstyle, pmd, findbug и др) (только для ветки dev) (mvn или другой вариант)
- Запуск измерения тестового покрытия (jacoco + mvn или другой)
- Инсталяция артефактов в локальный репозиторий только при успехе (mvn)
- Проверка критериев выпуска версии (процент покрытия строчек кода)
- Публикация (копирование) артефакта в заранее заданную папку (copy)
